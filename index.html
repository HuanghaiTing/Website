Features

能干活的 AI 助手

视觉识别

截图给 AI 看，它就能"看到"你的屏幕，找到按钮、输入框、菜单项，精准点击。

模拟操作

鼠标点击、双击、右键、拖拽、键盘输入、快捷键 —— 完全模拟真人操作。

📄

创建文档

网页操作

🔧

系统控制

打开设置、注册表、任务管理器、控制面板，一切系统工具随叫随到。

Get Started

三步开始使用

不用编译，不用配置环境，下载就能用。

1

下载安装包

去 Releases 下载最新的 .zip，解压到任意目录。

2

填入 API Key

双击 Project4.exe，点击右上角设置，填入你的通义千问或智谱 API Key。

3

开始使用

在输入框里描述你想做的事，比如"打开浏览器搜索 Python"，剩下的交给 AI。
